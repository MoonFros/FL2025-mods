EA FC 27 Broadcast - runtime folder
===================================

state.json in this folder is written by modules\FC27_Broadcast.lua about
10 times per second while the mod is running and is read by
fc27-overlay\FC27_Overlay.exe.

It is regenerated automatically on every game start - you can delete it at any
time, and it is safe to ignore it entirely if you do not use the HUD companion.

Nothing else is stored here (no save data, no EDIT data).
